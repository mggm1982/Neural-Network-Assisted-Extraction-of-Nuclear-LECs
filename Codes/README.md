# Inverse Scattering with Neural Networks

This repository contains the implementation of a neural-network-assisted approach to the inverse scattering problem of the internucleon potential. It infers short-range contact low-energy constants (LECs) for a truncated model  from  phase shifts.

## The Physics Problem
The nucleon-nucleon interaction is modeled using a simplified potential combining long-range one-pion exchange (OPE) and short-range contact interactions. The forward scattering problem is solved using a Lippmann-Schwinger equation to calculate phase shifts. 

The goal of this project is to solve the *inverse* problem: mapping observed phase shifts back to the underlying contact parameters (LECs). Because this relationship is highly non-linear, traditional optimization methods are computationally expensive. 

## The Machine Learning Pipeline
1. **Data Generation:** A synthetic dataset of 5,000 parameter samples was generated by uniformly sampling eight contact LECs and calculating their corresponding phase shifts using the forward solver. 
2. **Neural Network Inference:** A multilayer perceptron (MLP) was trained to map 66 phase-shift features (evaluated at 11 energies across 6 partial-wave channels) to the eight contact LECs.
3. **Physics-Based Refinement:** The neural network provides a rapid, highly accurate initial parameter estimate for empirical Nijmegen PWA93 phase shifts. This estimate is then passed to a bounded least-squares optimization routine for final refinement.

## EFT Renormalization
Because the implemented interaction model is a truncated approximation (omitting higher-order two-pion exchanges and the tensor-coupled $^3S_1$-$^3D_1$ channel), the final extracted LECs do not exactly match published literature values (like EMN500). 

This deviation is a direct demonstration of Effective Field Theory (EFT) renormalization: the neural network and optimizer dynamically shift the contact parameters to artificially absorb the missing, unresolved high-energy physics of the truncated model space.

## Running the Code
The core implementation is contained within the `Testing_Model_Code_3.ipynb` Jupyter Notebook. 

To run the pipeline:
1. Ensure the required libraries are installed (`numpy`, `pandas`, `scipy`, `sympy`, `matplotlib`, `tqdm`, `torch`, `scikit-learn`).
2. The notebook is structured to run sequentially:
   - Sets up the environment and defines physics constants.
   - Precomputes pion matrices and solves the Lippmann-Schwinger equation.
   - Generates the synthetic training data (`Training_Data/synthetic_n2lo_literature_units.csv`).
   - Trains the PyTorch MLP model.
   - Evaluates test-set recovery and extracts physical LECs from the Nijmegen data.
   - Generates comparison plots (saved in the `Codes/` directory).
